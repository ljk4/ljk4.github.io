将普通视频中的人体动作，通过 **MediaPipe 2D 姿态检测 → VideoPose3D 3D 姿态估计 → 逆运动学映射**，驱动 Unitree G1 人形机器人在 MuJoCo 物理引擎中做出相同动作。这是机器视觉课程的大作业项目。

## 项目结构

```
refactored/
├── run_pipeline.py                      # 一键式流水线入口
├── config.py                            # 共享配置
├── step1_inference/inference.py         # 步骤1: 2D视频→3D姿态
├── step2_ik_mapping/ik_mapping.py       # 步骤2: IK映射
├── step3_playback/playback.py           # 步骤3: MuJoCo仿真
├── action_recognition/                  # 2D动作语义识别
├── skeleton_viewer/                     # 3D骨架可视化
├── video_composer/                      # 多视频布局组合工具
├── utils/                               # 共享工具模块
├── model/                               # ML 模型文件
├── unitree_g1/                          # G1 机器人模型 (29 DOF)
└── output/                              # 所有生成文件
```

## 技术栈

| 组件 | 技术 |
|---|---|
| 2D 姿态检测 | MediaPipe Pose |
| 3D 姿态估计 | VideoPose3D (ONNX) |
| 逆运动学 | mink |
| 物理仿真 | MuJoCo |
| 机器人模型 | Unitree G1 (29 DOF) |
| 数据处理 | NumPy, SciPy, OpenCV |

## 使用方法

### 一键式流水线

```bash
# 完整流程: 推理 → IK映射 → 播放 → 动作识别 → 骨架可视化 → 最终对比视频
python run_pipeline.py

# 已有中间结果, 跳过某些步骤
python run_pipeline.py --skip-inference     # 已有 taiji.npz
python run_pipeline.py --only-final         # 仅合成最终对比视频
```

### 分步执行

```bash
# 步骤1: 2D视频 → 3D姿态推理 → output/step1_3d_inference.mp4
python step1_inference/inference.py

# 步骤2: 人体骨架 → G1关节角映射 → output/step2_ik_mapping.mp4
python step2_ik_mapping/ik_mapping.py

# 步骤3: MuJoCo播放G1动画 → output/step3_mujoco_playback.mp4
python step3_playback/playback.py --save
```

### 独立模块

```bash
# 2D动作识别
python action_recognition/action_classifier.py

# 3D骨架可视化（动画/静态帧）
python skeleton_viewer/viewer.py --animate
python skeleton_viewer/viewer.py --frame 100

# 组合对比视频
python video_composer/compose.py \
    output/step1_3d_inference.mp4 \
    output/step2_ik_mapping.mp4 \
    output/step3_mujoco_playback.mp4 \
    -o output/comparison.mp4 --layout horizontal
```

## 技术要点

1. **2D→3D 姿态估计**：MediaPipe 提取 33 个 2D 关键点，VideoPose3D 将其提升为 3D 坐标
2. **骨架映射**：将 Human3.6M 骨架结构映射到 G1 的 29 个自由度关节空间
3. **逆运动学求解**：通过 mink 库将末端位置转换为关节角度
4. **物理仿真**：MuJoCo 提供高保真物理环境，验证映射动作的可行性
