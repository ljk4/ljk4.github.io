从多视角二维图像恢复三维场景结构是计算机视觉的核心问题之一。本项目使用纯 Python + OpenCV 实现了一个完整的增量式 Structure from Motion (SfM) 管道，输入一组无序照片，输出相机位姿和三维稀疏点云。

## 管道架构

```
main.py
  ├── self_calibration.py        # EXIF 读取焦距 → 精确内参矩阵 K
  ├── feature_matching.py        # SIFT + FLANN 特征匹配
  ├── sfm_pipeline.py            # 增量式 SfM 主循环
  ├── bundle_adjustment.py       # 迭代 PnP LM + 多视图重三角化
  ├── export_results.py          # PLY 导出（点云 + 相机视锥）
  └── visualize.py               # Open3D 交互可视化
```

## 关键技术

### 1. 自标定：从 EXIF 读取焦距

传统 SfM 需要标定板或从图像估计内参。本项目直接从 JPG 的 EXIF 数据读取焦距和传感器尺寸，通过查表获得精确的内参矩阵 $K$。无 EXIF 时自动回退到基础矩阵 $F$ 估计。

### 2. 特征提取与匹配

使用 **SIFT** 提取每张图像的特征点和描述子，通过 **FLANN + Lowe's ratio test**（阈值 0.7）进行相邻帧匹配。SIFT 的尺度不变性让同一物体在不同距离和角度下仍能稳定匹配。

### 3. 增量式 SfM

核心流程为：

1. **初始化**：在所有候选相邻帧对中，选基础矩阵 $E$ 内点最多的相邻对作为种子
2. **位姿估计**：$F$（RANSAC） → $E$ → Cheirality 检验选正确解
3. **增量注册**：PnP EPnP + RANSAC，每次迭代 200 次
4. **发散检测**：步长 > 历史中位数×2 或跳变 > 预期×10 时自动停止

### 4. 光束法平差（Bundle Adjustment）

采用迭代 PnP LM（motion-only）优化每帧的相机位姿，结合最大基线重三角化添加新三维点。通过重投影误差 5px 阈值和距离 MAD 鲁棒过滤剔除离群点。

### 5. 结果过滤

- 重投影误差 > 5px 的点被剔除
- 距离超过 MAD 阈值的离群点被过滤
- 确保最终点云干净可用

## 实验结果

**数据集**：Cat_RGB — 108 张 2272×1704 JPG（Panasonic DMC-GF6, 33mm 焦距），绕物体拍摄约 3 圈。

| 指标 | 数值 |
|------|------|
| 相机注册率 | **100%**（108/108） |
| 稀疏点云规模 | ~77K SIFT 特征点三角化 |
| 重投影误差中位数 | **0.11 px** |
| 处理耗时 | ~2 分钟（1200px 缩略图） |

## 为什么不用 COLMAP？

COLMAP 是业界标准的 SfM/MVS 工具，但本项目选择手动实现，目的有三：

1. **理解底层原理**：SfM 每个环节（特征匹配、几何验证、PnP、三角化、BA）的数学原理只有亲手实现才能深入理解
2. **可控性**：可以在任意环节插入调试信息，观察中间结果
3. **教学价值**：代码结构清晰，每个模块独立，便于学习和修改
