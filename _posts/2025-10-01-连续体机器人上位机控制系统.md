本项目是"机器人结构设计"课程的大作业，以小组为单位完整经历了从概念设计到实物验证的机器人开发全流程。我负责上位机控制系统的需求分析、架构设计、编码实现与系统联调。

## 项目概述

设计并实现了一套绳驱动连续体机器人（Cable-Driven Continuum Robot）的上位机控制系统。系统基于分段常曲率（PCC）运动学模型，实现了包含逆运动学求解、串口通信、实时控制及三维可视化在内的完整控制管线。

**关键指标**：

- 50Hz 实时控制循环
- 39 字节定长帧协议（CRC16-Modbus 校验）与 STM32 下位机通信
- 控制 8 根腱绳驱动两段连续体机械臂
- IK 末端定位误差 < 1mm
- 支持四种控制模式：手动输入、视觉伺服（AprilTag）、预设轨迹跟踪、图像搜索伺服

## 机械结构

机器人采用两段式串联结构，样机总质量仅 78.8g，总长度 615.6mm，主体直径 40mm。核心设计亮点是通过三种模块化刚度单元实现"根部刚、末端柔"的刚度梯度分布，解决了柔性结构承载刚度不足的矛盾。

## 个人主要贡献

### 视觉伺服

基于 AprilTag 实现了两种视觉伺服模式：

- **眼在手外模式**：单目相机检测 AprilTag，solvePnP 解算 6-DOF 位姿，经坐标变换后驱动 IK 实现末端跟踪
- **眼在手上模式**：纯像素偏差驱动的图像伺服算法，包含螺旋扫描搜索、目标锁定（死区+滞回）和自动跟踪的完整闭环

### 运动学求解优化

在组员完成的 PCC 正/逆运动学基础上进行了工程优化：

- 建立坐标系与绳驱动方位的关联，确保运动学模型与物理绳路一致
- 添加安全约束（弯曲角硬限幅 + 软约束惩罚函数）
- 实现多目标优化框架：阻尼最小二乘法配合最小位移正则化、弯曲角惩罚、绳长惩罚

### 通信协议

设计了 39 字节定长帧协议，包含 CRC16-Modbus 校验、帧解析状态机和多线程收发架构。后期增加了 ACK 超时检测、串口写超时保护和发送器急停模式等故障安全机制。

### 相机标定

实现了基于棋盘格的内参标定工具，包括图像采集与角点检测、标定求解与参数保存，并将标定结果集成到视觉伺服管线中。

┌─────────────────────────────────┐
│         GUI (tkinter)           │

├─────────────────────────────────┤
│      主控制循环 (50Hz)           │
│  ┌─────┐  ┌──────┐  ┌───────┐  │
│  │ IK  │  │视觉  │  │轨迹   │  │

│  └─────┘  └──────┘  └───────┘  │

│   CRC16-Modbus | ACK超时检测    │

## 技术栈

| 类别 | 技术 |
|------|------|
| 运动学模型 | PCC（分段常曲率） |
| 逆运动学 | 阻尼最小二乘法 + 多目标惩罚优化 |
| 视觉伺服 | AprilTag + solvePnP |
| 物理仿真 | MuJoCo |
| GUI | tkinter |
| 通信 | UART, CRC16-Modbus |
| 相机标定 | 棋盘格 + OpenCV |
| 机械制造 | 3D 打印 (PLA), SolidWorks 建模 |

## 结果验证

- IK 末端定位误差在 1mm 以内
- 通信帧往返验证无误，ACK 响应正常
- 四种控制模式在仿真环境中均完成全流程验证
- Abaqus 有限元校核：5N 载荷下安全系数 3.285，满足工程要求
