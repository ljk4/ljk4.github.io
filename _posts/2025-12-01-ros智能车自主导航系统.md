本项目是北京科技大学第十九届智能车竞赛 ROS 组的完整解决方案，基于 ROS Noetic 开发，获得 **ROS 组一等奖第三名**。

赛题要求在 Gazebo 仿真环境中完成自主导航、目标识别、二维码任务解析和语音播报等一系列任务。我独立完成了从建图到决策的全流程开发。

![导航最终效果展示](/assets/img/smartcar/导航最终效果展示.gif)

## 核心功能

- **自主导航**：基于 Cartographer 建图和 move_base 的自主导航与动态避障
- **目标检测**：集成 YOLOv5 进行实时物体识别（3 类以上物品）
- **二维码识别**：自动识别和处理二维码中的任务信息
- **语音播报**：在任务领取、取货、结算三个关键节点同步语音反馈
- **任务调度**：基于 SMACH 的状态机控制逻辑，实现多任务协调执行
- **仿真环境**：基于 Gazebo 的高保真仿真环境，脚本一键生成随机任务

## 项目组成

项目包含多个 ROS 包：

| 包名 | 功能 |
|------|------|
| `detection_msgs` | YOLOv5 目标检测消息定义 |
| `final_task` | 主任务控制包，协调各子系统 |
| `gazebo_pkg` | Gazebo 仿真环境和模型 |
| `image_task` | 图像识别任务实现 |
| `mecanum_sim` | 麦克纳姆轮小车模型 |
| `qr` / `qr_msgs` | 二维码识别与消息定义 |
| `ucar_navigation` | 导航配置与参数 |
| `yolov5_ros` | YOLOv5 目标检测集成 |

## 使用方法

```bash
# 克隆项目
git clone https://github.com/ljk4/ustb_19th_smartcar.git
cd ustb_19th_smartcar/catkin_ws

# 构建
source /opt/ros/noetic/setup.bash
rosdep install --from-paths src --ignore-src -r -y
catkin_make
source devel/setup.bash

# 启动完整任务
roslaunch final_task fin.launch
```

### Docker 一键部署

```bash
docker build -t smartcar:noetic .
chmod +x run_docker.sh
./run_docker.sh
# 进入容器后
catkin_make
source devel/setup.bash
roslaunch final_task fin.launch
```

## 导航与决策

- **建图**：Cartographer SLAM，覆盖包含坡道、锥桶、障碍板等复杂地形
- **全局路径规划**：通过随机障碍区域，实现无碰撞满分行进
- **状态机决策**：根据二维码动态信息实时解析目标序列，全流程自主执行时间约 3 分钟
- **比赛表现**：在仅有的 3 次发车机会内实现稳定复现，决赛无碰撞、无扣分

## 技术要点

1. **多传感器融合**：摄像头 + 激光雷达数据协同，支撑 YOLOv5 检测与 move_base 避障
2. **模块化架构**：各 ROS 包独立开发、独立测试，通过 topic/service 松耦合通信
3. **仿真保真度**：Gazebo 环境中加入随机障碍物、光照变化等扰动，提高算法鲁棒性
4. **一键部署**：Docker 化打包，降低环境配置复杂度
