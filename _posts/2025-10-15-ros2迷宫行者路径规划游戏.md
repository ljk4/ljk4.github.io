本项目是一个全栈交互式的 ROS2 路径规划游戏，展示了如何结合 ROS2 Humble、Docker、WebSockets 和 HTML5 Canvas 进行机器人全栈开发。

在线体验地址：[http://49.232.161.225/](http://49.232.161.225/)

## 主要特性

### 挑战模式

- **随机关卡**：每次点击都会生成带有随机障碍物的全新地图
- **交互式玩法**：使用鼠标从绿色起点 (S) 拖拽画线到红色终点 (G)
- **AI 提示**：点击按钮让 ROS2 后端使用 A* 算法为玩家解题

### 自定义模式（沙盒）

- **地图编辑器**：设计自己的迷宫
- 左键设置起点、右键设置终点、Shift + 点击添加或移除墙体
- **AI 求解**：实时验证迷宫是否有解

## 技术架构

| 层级 | 技术栈 |
|------|--------|
| **前端** | HTML5, JavaScript (Canvas API), roslibjs |
| **后端** | Python ROS2 节点 |
| **通信** | rosbridge_server WebSocket |
| **部署** | Docker Compose 多阶段构建 |

### 核心功能

- 订阅 `/game_request` 主题接收地图数据
- 发布 `/game_response` 主题返回路径坐标
- 寻路算法：**A\*** 路径搜索
- Web 服务：Nginx 反向代理 + Python HTTP Server

## CI/CD 与构建优化

### 双层镜像构建策略

1. **基础镜像** — 包含 Ubuntu 22.04, ROS2 Humble 核心组件及 Python 依赖，已推送至 Docker Hub
2. **应用镜像** — 仅包含业务代码和前端文件，利用 Docker 层缓存，构建速度 < 10s

### GitHub Actions 工作流

| 工作流 | 触发条件 | 任务 |
|--------|----------|------|
| CI - Build & Test | 任意分支 push | 安装依赖、编译、代码静态分析、单元测试 |
| CD - Build & Deploy | main 分支推送 | 多架构镜像构建、Docker Hub 推送、SSH 自动部署 |

## 项目结构

```
MyCloudRobot/
├── docker/                 # Docker 配置（多阶段构建、Nginx）
├── ros_ws/src/
│   └── cloud_monitor_pkg/
│       ├── path_planner_node.py  # 核心寻路逻辑 (A*)
│       └── launch/system.launch.py
├── tests/                  # 集成测试
├── web/index.html          # 游戏主界面 (HTML5 Canvas)

```

## 本地部署

```bash
git clone https://github.com/ljk4/MyCloudRobot.git
cd MyCloudRobot
docker compose up --build
# 访问 http://localhost
```
