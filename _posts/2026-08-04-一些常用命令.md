日常开发中总有些命令隔段时间不用就忘，每次都要翻文档。本文作为一个持续更新的速查手册，记录常用但容易遗忘的命令和代码片段。

## Linux 包管理

### 安装 deb 包

```bash
# 安装 .deb 安装包
sudo dpkg -i package_name.deb

# 处理依赖问题
sudo apt -f install
```

## Python 常用代码

### Matplotlib 中文显示与负号修复

```python
import matplotlib.pyplot as plt

# 设置字体为 SimHei 显示中文
plt.rcParams['font.sans-serif'] = ['SimHei']
# 允许显示负号
plt.rcParams['axes.unicode_minus'] = False
```

### 屏蔽日志输出

```python
import logging
logging.basicConfig(level=logging.WARNING)
```

## uv 包管理工具

### 创建项目

```bash
uv init my_project
cd my_project
```

### 添加依赖

```bash
# 添加生产依赖
uv add requests

# 添加指定版本
uv add "requests>=2.31.0"

# 添加开发依赖
uv add --dev pytest ruff
```

### 移除依赖

```bash
uv remove requests
```

### 从 pyproject.toml 安装全部依赖

```bash
uv sync
```

### 添加镜像源

在 `pyproject.toml` 中添加：

```toml
[tool.uv]
index-url = "https://pypi.tuna.tsinghua.edu.cn/simple"
```

### 锁定依赖版本

```bash
uv lock
```

### 直接运行脚本

```bash
uv run main.py
```
