PUMA560 是经典的六自由度工业机器人，具有球腕结构（后三个关节轴线交于一点），满足 Pieper 准则，存在封闭形式的逆运动学解。本项目使用 SymPy 进行完整的符号推导和数值验证。

## 1. 改进 DH 建模

采用改进 DH（Modified DH, MDH）方法建立运动学模型。MDH 的连杆变换矩阵定义为：

$$
{}^{i-1}T_i = \mathrm{Rot}_x(\alpha_{i-1})\,
               \mathrm{Trans}_x(a_{i-1})\,
               \mathrm{Rot}_z(\theta_i)\,
               \mathrm{Trans}_z(d_i)
$$

展开为齐次矩阵：

$$
{}^{i-1}T_i =
\begin{bmatrix}
    c_i & -s_i & 0 & a_{i-1} \\
    s_i c_{\alpha_{i-1}} & c_i c_{\alpha_{i-1}} & -s_{\alpha_{i-1}} & -d_i s_{\alpha_{i-1}} \\
    s_i s_{\alpha_{i-1}} & c_i s_{\alpha_{i-1}} &  c_{\alpha_{i-1}} &  d_i c_{\alpha_{i-1}} \\
    0 & 0 & 0 & 1
\end{bmatrix}
$$

PUMA560 改进 DH 参数表：

| 关节 $i$ | $\alpha_{i-1}$ | $a_{i-1}$ (m) | $d_i$ (m) | $\theta_i$ |
|:--------:|:--------------:|:-------------:|:---------:|:----------:|
| 1 | 0 | 0 | 0 | $\theta_1$ |
| 2 | $-\pi/2$ | 0 | 0 | $\theta_2$ |
| 3 | 0 | 0.4318 | 0.15005 | $\theta_3$ |
| 4 | $-\pi/2$ | 0.0203 | 0.4318 | $\theta_4$ |
| 5 | $\pi/2$ | 0 | 0 | $\theta_5$ |
| 6 | $-\pi/2$ | 0 | 0 | $\theta_6$ |

## 2. SymPy 符号正运动学

使用 SymPy 逐关节构建变换矩阵并连乘：

```python
def mdh(alpha, a, d, theta):
    """Modified DH: T = Rot_x(alpha) * Trans_x(a) * Rot_z(theta) * Trans_z(d)"""
    ca, sa = sp.cos(alpha), sp.sin(alpha)
    ct, st = sp.cos(theta), sp.sin(theta)
    return sp.Matrix([
        [ct, -st, 0, a],
        [st*ca, ct*ca, -sa, -d*sa],
        [st*sa, ct*sa,  ca,  d*ca],
        [0, 0, 0, 1]
    ])

T01 = mdh(0,       0,  0,  theta1)
T12 = mdh(-sp.pi/2, 0,  0,  theta2)
T23 = mdh(0,        a2, d3, theta3)
T34 = mdh(-sp.pi/2, a3, d4, theta4)
T45 = mdh(sp.pi/2,  0,  0,  theta5)
T56 = mdh(-sp.pi/2, 0,  0,  theta6)

T06 = sp.simplify(T01 * T12 * T23 * T34 * T45 * T56)
```

符号推导输出全部以 LaTeX 格式保存，可直接用于学术报告。

## 3. 全 8 组逆运动学解

PUMA560 满足 Pieper 准则（后三个关节轴交于一点），存在 **8 组封闭解**，由三组二选一分支构成：

| 分支 | 选项 | 来源 |
|------|------|------|
| 肩部 | 左肩 / 右肩 | $\theta_1$ 的两组解 |
| 肘部 | 肘上 / 肘下 | $\theta_3$ 的两组解 |
| 腕部 | 腕正 / 腕反 | $\theta_5$ 的正负 |

### 求解步骤

1. **$\theta_1$**：由末端位置 $p_x, p_y$ 和肩部偏置 $d_3$ 解得左肩/右肩两组解
2. **$\theta_3$**：由位置几何关系解出肘上/肘下两组
3. **$\theta_2$**：由 $\theta_1, \theta_3$ 唯一确定
4. **$\theta_4, \theta_5, \theta_6$**：由 $R_{36} = R_{03}^T \cdot R_{06}^{\text{target}}$ 分离手腕角度

### 数值验证

以一组给定关节角做正运动学得到目标位姿，再用逆运动学反算，将反算结果重新正解，比较与目标位姿的差异：

```
给定: θ1=30°, θ2=40°, θ3=-20°, θ4=10°, θ5=50°, θ6=80°

全 8 组逆解概览:
#   构型                θ1     θ2     θ3     θ4     θ5     θ6     误差
1   左肩+肘下+腕正   30.00  40.00 -20.00  10.00  50.00  80.00  1.23e-14
2   左肩+肘下+腕反   30.00  40.00 -20.00 190.00 -50.00 260.00  1.45e-14
3   左肩+肘上+腕正   30.00  91.43  20.00 -93.72  50.00  21.20  3.56e-14
...
```

> 所有 8 组解的误差均在 **10⁻¹⁴** 量级，验证了符号推导和数值实现的正确性。
