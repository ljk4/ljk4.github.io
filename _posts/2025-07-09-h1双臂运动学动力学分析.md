本项目基于 MuJoCo 物理引擎和 Unitree H1 人形机器人模型，对固定骨盆双臂系统（9 自由度：躯干 1 + 左臂 4 + 右臂 4）进行系统的运动学与多体动力学分析，共完成六个独立实验。

> 原始 H1 模型已移除下半身（双腿 + 骨盆自由关节），骨盆直接固定于世界坐标系，仅保留上半身 9 个关节。

## 实验一：FK 工作空间分析

**目标**：通过正向运动学采样，可视化双臂末端可达区域。

随机采样 5000 组关节角度配置，计算左右手腕在三维空间中的位置分布。

| 指标 | 数值 |
|------|------|
| 采样数 | 5000 组随机关节角 |
| X 范围 | ±0.80 m |
| Y 范围 | ±0.80 m |
| Z 范围 | 0.91–2.11 m |
| 输出 | 3D 手腕点云图 |

## 实验二：双臂 IK 收敛验证

**目标**：验证逆运动学求解器的收敛性能。

从 FK 采样点中选取对称目标位姿，使用 `mink` 微分 IK + QP 求解器追踪，验证收敛精度。

| 指标 | 左臂 | 右臂 |
|------|------|------|
| 收敛步数 | 7 | 7 |
| 最终位置误差 | 0.46 mm | 0.34 mm |

> **7 步收敛至亚毫米精度**，说明微分 IK 求解器对该系统具有良好的收敛性。

## 实验三：双臂提升（逆动力学）

**目标**：计算双臂同时提升重物时各关节所需的驱动力矩。

采用 S 曲线轨迹规划平滑运动，通过逆动力学（ID）计算各关节力矩。输出包含各关节力矩变化曲线和运动过程视频。

| 指标 | 数值 |
|------|------|
| 肩关节峰值力矩 | 1.88 Nm |
| 轨迹类型 | S 曲线（加加速度连续） |

## 实验四：动态耦合效应

**目标**：量化单臂运动与双臂运动的躯干耦合差异。

分别执行单臂提升和双臂同步提升，比较躯干和肩关节的力矩差异。

| 指标 | 数值 |
|------|------|
| 躯干力矩耦合差异（均值） | 0.0632 Nm |
| 躯干力矩耦合差异（峰值） | 0.1288 Nm |

> 耦合效应较小（均值 < 0.1 Nm），说明在慢速提升任务中双臂的动力学耦合可以近似忽略。

## 实验五：质量矩阵分析

**目标**：分析系统 9×9 关节空间质量矩阵的结构。

| 指标 | 数值 |
|------|------|
| 躯干自惯量 | 0.5922 kg·m² |
| 矩阵维度 | 9×9 |
| 输出 | 热力图可视化 |

质量矩阵热力图直观展示了各关节之间的惯性耦合强度，非对角线元素的大小反映了关节间动态耦合的显著程度。

## 实验六：ID-FD 闭环验证

**目标**：验证逆动力学（ID）与正向动力学（FD）的自洽性。

用逆动力学计算力矩 → 正向动力学仿真加速度 → 比较理论与仿真加速度。

| 指标 | 数值 |
|------|------|
| ID-FD 闭环误差 (MAE) | **2.38×10⁻¹⁶ rad/s²** |

> 误差达到机器精度量级，验证了 MuJoCo 引擎中 ID 与 FD 的数值自洽性，也确认了模型参数设置的正确性。
